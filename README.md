# Lumina Code

Claude API 専用の、個人用ローカルチャットアプリ「Lumina Code」（Windows）の配布用リポジトリです。

- このリポジトリには、リリース（インストーラーと更新情報）だけを置きます。ソースコードは含みません。
- インストーラーは [Releases](https://github.com/iijimatakayuki0402/LuminaCode/releases) からダウンロードできます。
- インストール済みのアプリは、このリポジトリのリリースから更新を確認します。

## 注意

- インストーラーにはコード署名をしていません。初回の実行時に Windows SmartScreen の警告が表示されることがあります。
- 利用には Anthropic の API キーが必要です。
