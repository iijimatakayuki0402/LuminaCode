## 実装・実機確認で見つけて直した問題

- **拡張思考のオフが効いていなかった（CHT-07）**：今のモデルは `thinking` を省いても思考する（Sonnet 5.5 は adaptive が既定、Opus 5.5 は止められない）。オフのときは `disabled` → `between_tools` の順に試し、受け付けられた指定をモデルごとに覚えるようにした。実 API では、Sonnet 5.5 が `disabled` を拒否し、`between_tools` を受け付けた（2 回目以降は最初から `between_tools` を送る）。Cowork では思考のオン／オフを渡さないようにした。
- **Web 検索の表示（CHT-11）**：結果を絞り込む版（`web_search_20260209`）では、Claude がコード実行から検索を呼び、本文に引用が付かないことがある。検索語は検索のブロックから取り、引用が無いときは検索結果を「検索結果」として示すようにした。
- **検索をオフにした後の会話（CHT-11）**：以前の検索結果を外して送ると、モデルが「前の回答は調べていなかった」と誤って訂正した。オフにした後も以前の検索結果は残し、検索ツールを定義したうえで使わせない（`tool_choice: none`）ようにした。
- **通知（COW-07）**：最初の発言から作ったスレッド名（会話の内容）を通知に出していた。手動・AI のタイトルだけを出すようにした。

## 確認して分かったこと

- 簡単な質問では、拡張思考がオンでも思考しないことがある（adaptive thinking の仕様）。そのため、オンとオフの違いは回答だけでは分からない。オフの指定が受け付けられたことはログで確認した。
- 結果を絞り込む版の Web 検索は、検索結果を読み込むため 1 回の回答で約 3 万トークンを使う（Sonnet 5.5 で約 0.04〜0.05 USD）。
- renderer から `window.close()` で閉じた場合はウィンドウの状態が保存されない（`close` イベントが出ない）。× ボタンや Alt+F4 などの通常の閉じ方では保存される。
