## 実機確認で見つけて直した問題

- **todo のパネルが表示されない（COW-13）**：現在の Claude Code は TodoWrite の代わりに Task 系のツール（TaskCreate／TaskUpdate など）を使う。Cowork のツール一覧に含めていなかったため、一覧が作られなかった。Task 系のツールを許可し、PostToolUse の結果から一覧を組み立てるようにした。
- **サブエージェントの結果が回答に入らない（6.6）**：Agent ツールの既定がバックグラウンド実行になっており、メインの回答が結果を待たずに終わっていた。Cowork は依頼ごとに実行して終わるため、`CLAUDE_CODE_DISABLE_BACKGROUND_TASKS` でバックグラウンド実行を無効にした。
- **会話の表示欄が潰れる**：Cowork で todo のパネルなどが並ぶと、既定のウィンドウの大きさで会話の表示欄が十数ピクセルまで縮んでいた。表示欄に最低限の高さを付け、todo のパネルには高さの上限を付けた。
- **ファイルツリーが更新されない**：Cowork の実行が終わったら、開いているフォルダを読み直すようにした。

## 確認して分かったこと

- adaptive thinking は、思考量が少なく簡単な質問では考えずに答えることがある（オンでも思考の要約が出ない）。
- 思考の要約は英語で表示されることがある（モデルの出力のまま）。
- 開発版の通知の差出人は「Electron」と表示される（パッケージ版はアプリの ID を使う）。
- Haiku 4.5 は adaptive thinking に対応していないため、拡張思考の切り替えは表示しない。
