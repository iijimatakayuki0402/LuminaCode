# Lumina Code 要望書

| 項目 | 内容 |
|---|---|
| アプリ名 | Lumina Code |
| 作成日 | 2026-10-02 |
| 利用形態 | 個人用ローカルチャットアプリ |
| 利用API | Claude API 専用 |

## 1. 概要

Claude API 専用の個人用ローカルチャットアプリ「Lumina Code」を作成する。
プロジェクト単位で会話・設定を管理し、通常のチャット（ファイル参照対応）と、指定フォルダを操作できる Cowork の2種類のプロジェクトを扱えるようにする。

## 2. ダッシュボード

- ダッシュボードでプロジェクトを一覧・管理する。
- 設定ボタンを設置する。
- プロジェクトは種別で色分けする。
  - 通常チャット：色A
  - Cowork：色B
  （具体的な色は要件定義で決定する）

## 3. プロジェクト作成機能

- プロジェクト新規作成時に、種別として「通常チャット」または「Cowork」を選択できる。
- どちらの種別でも**カスタム指示**を作成できる。
- プロジェクト名を設定する（**必須**）。
- Cowork の場合、フルアクセスを許可するフォルダを**1つ**設定する（**必須**）。

### 入力項目一覧

| 項目 | 通常チャット | Cowork |
|---|---|---|
| プロジェクト名 | 必須 | 必須 |
| カスタム指示 | 任意 | 任意 |
| フルアクセスフォルダ（1つ） | - | 必須 |

## 4. 通常チャット

- Claude チャットアプリのように、ファイルをアップロードし、そのファイルを参照・利用して会話できる。
- ファイルがなくても会話できる。

## 5. Cowork

- 指定したフォルダに対してフルアクセスできる（読み取り・作成・編集・削除）。
- チャットで削除の指示があった場合は、ファイル／フォルダを削除できる。
- 公式提供の Claude CLI（Claude Code）の機能を可能な限りすべて利用できるようにする。ただし、アプリでは実装できない機能は除く。
- 操作範囲は指定フォルダ内とする。

## 6. その他

- モデルを選択できる。
- 利用できるのは Claude API のみ。API キーの設定は**必須**とする。

## 7. 追加機能要望

優先度の区分は、要件定義で確定する。

### 7.1 セキュリティ・安全性・運用

1. **API キーの安全な保管**
   - 保管先は Windows 資格情報マネージャーまたは DPAPI 暗号化とする。平文の設定ファイルには保存しない。
   - 初回起動時にキー入力を求め、キー検証（疎通テスト）を行う。
2. **Cowork の安全策**
   - 削除・上書きの前に確認ダイアログを表示する。「今回は許可」「常に許可」「毎回確認」を選択できる。
   - 指定フォルダ外へのアクセスを強制的に防ぐ（パストラバーサル、シンボリックリンク、ジャンクション対策）。
   - 削除はごみ箱経由、または専用の `.lumina-trash` への移動とし、復元できるようにする。
   - 操作ログ（日時・対象ファイル・操作内容）を記録する。
   - ファイル変更の差分表示と、一括の元に戻す（Undo）を提供する。
3. **利用料金・トークンの可視化**
   - 1回ごと・累計の使用トークンと概算コストを表示する。
   - 月額、およびプロジェクトごとの上限を設定でき、超過時は警告または停止する。
4. **バックアップ・エクスポート**
   - プロジェクト全体と会話履歴を JSON／Markdown で書き出し、読み込める。

### 7.5 あると便利（後回し可）

- 定型プロンプト（スニペット）の保存
- 会話の要約・タイトル自動生成
- Web 検索ツール（API の server tool）の有効化
- 複数フォルダの許可（現在は1つ。将来は読み取り専用フォルダの追加など）

### 7.6 対象外

- 音声入力・音声読み上げ（Windows 標準の音声入力 Win+H で代用できるため、初期リリースでは実装しない）

### 7.7 デザイン・チャット機能の追加要望

**Lumina Code のデザイン**

- 設定で、アクセントカラーを次の3色から選択できる。
  - 薄紫
  - 水色
  - 薄い赤色
- 設定で、表示モードを「ダーク」「ライト」「標準」から選択できる。
- システムチックで、かっこいい雰囲気のチャット画面にする。

**チャットへの追加機能**

- 回答チャットの下に、回答をコピーするコピーボタンを置く。
- 直近に送信した指示は編集可能とし、編集後に再送信できるようにする。
